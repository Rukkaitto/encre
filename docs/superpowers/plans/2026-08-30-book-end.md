# End of book — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Paging forward off the last page of the last chapter opens
`design/BookEnd.dc.html` instead of doing nothing, and `MARK AS FINISHED` there
and on the item-actions overlay writes a real per-book flag.

**Architecture:** A `finished` bool on `ReadingPosition`, carried through
`ProgressEntry` so the Library learns it from the listing it already does. A new
`ScreenId::BookEnd` deriving from `FocusScreen(2, 2)`. Storage stays in the shell
via a latched `Action::finish()`, exactly as `Action::open()` and `Action::retry()`
already work. `walkToChapter`'s bool becomes a three-state result so "the book
ended" is distinguishable from "the archive is broken".

**Tech stack:** C++20, `core/` portable (no Arduino/ESP/host-OS), doctest,
CMake+`file(GLOB)`, PlatformIO for firmware, Python for the asset generators.

**Spec:** `docs/superpowers/specs/2026-08-30-book-end-design.md`

---

## Before you start

Read `docs/superpowers/specs/2026-08-30-book-end-design.md` and the **Invariants
worth not relearning** section of `CLAUDE.md`. Three project rules govern almost
every task here:

1. **A UI change goes into the design HTML first**, then the implementation. Task 1
   exists because of this and must land before Task 7.
2. **Never re-bless a golden to make a test pass.** Look at the candidate PNG with
   the Read tool, walk the board item by item, say what you see.
3. **`cmake -S . -B build` after adding or removing a source file.** CMake uses
   `file(GLOB ...)`, so a new file is silently ignored otherwise.

`make test` is the fast loop. Run it after every task.

    #    ~49 s of decode and there is no clock. 24 CHAPTERS is chapterCount(),
    #    which Main.dc.html already says `OF` for this same demo book.
    ('<div style="font-size: var(--t-meta); letter-spacing: 0.14em;">890 PAGES &middot; FINISHED AUG 20</div>',
     '<div style="font-size: var(--t-meta); letter-spacing: 0.14em;">24 CHAPTERS</div>'),
]
for old, new in edits:
    assert s.count(old) == 1, f"anchor not found exactly once: {old[:60]}"
    s = s.replace(old, new, 1)

# 4. The slabs: kActionH is 68 and four other boards state it. TWO occurrences.
old = "height: 72px; display: flex; align-items: center; justify-content: center"
new = "height: 68px; display: flex; align-items: center; justify-content: center"

// THE FLAG IS AN ASSERTION, NOT A MEASUREMENT, and it round-trips.
TEST_CASE("finished round-trips through serialise and parsePosition") {
  reader::ReadingPosition p;
  p.bookPath = "/books/Middlemarch.epub";
  p.spine = 3;
  p.finished = true;

  reader::ReadingPosition back;
  REQUIRE(reader::parsePosition(reader::serialise(p), back));
  CHECK(back.finished == true);
  CHECK(back.spine == 3);
}

// THE ASSERTION THAT ACTUALLY MATTERS. savePosition goes through writeIfChanged,
// which reads the card back and compares BYTES -- so a `finished: false` written
// unconditionally would change every existing sidecar's text and rewrite the lot
// on their next save, a card write per book to record nothing. Absent-when-false
// is the same rule the anchor's three keys already follow.
TEST_CASE("an unfinished position serialises to the bytes it did before the field existed") {
  reader::ReadingPosition p;
  p.bookPath = "/books/Middlemarch.epub";
  p.spine = 3;
  p.block = 7;
  p.finished = false;

  CHECK(reader::serialise(p).find("finished") == std::string::npos);
}

// A record written before this field existed must still load -- with `finished`
// defaulting false, not with the parse refusing. kPositionVersion deliberately did
// NOT move: bumping it would make every reader lose their place in every book, to
// protect against a downgrade whose worst outcome is a missing label.
TEST_CASE("a record with no finished key parses, defaulting to unfinished") {
  reader::ReadingPosition p;
  p.bookPath = "/books/Walden.epub";
  p.spine = 1;
  const std::string before = reader::serialise(p);

  reader::ReadingPosition back;
  back.finished = true;  // seeded true, so a parse that ignores the field is caught
  REQUIRE(reader::parsePosition(before, back));
  CHECK(back.finished == false);
}

// operator== has to see it, or "did the position change" answers wrongly for the
// one field this feature adds.
TEST_CASE("two positions differing only in finished are not equal") {
  reader::ReadingPosition a;
  a.bookPath = "/books/Walden.epub";
  reader::ReadingPosition b = a;
  b.finished = true;
  CHECK_FALSE(a == b);
}

Action BookEndScreen::onGesture(const GestureEvent& g) {
  switch (g.what) {
    case Gesture::Next:
      return moveFocus(+1, g.held);
    case Gesture::Prev:
      return moveFocus(-1, g.held);
    case Gesture::Back:
      // BACK TO THE LAST PAGE, which is why this screen is pushed rather than
      // swapped in. A reader who wanted to re-read the ending can.
      return Action::pop();
    case Gesture::Activate:

          // the reader arrived through CONTINUE. The LABEL is what varies; see
          // BookEndViewModel::leaveLabel.
          return Action::popTo(ScreenId::Library);
        default:
          return Action::none();
      }
    default:
      return Action::none();
  }
}

  const Font& noteF = fonts[Role::Meta400];

  //

  // truncating divisions once put an icon 1.5px low on another screen.

                  baselineInF26(titleF, yF26, pxToF26(titleF.lineHeight())), vm.title,
                  Ink::Black, trackingEm(titleF, kBookEndTitleEm), plane);
  yF26 += pxToF26(titleF.lineHeight() + kBookEndGap);

                  baselineInF26(bylineF, yF26, pxToF26(bylineF.lineHeight())), vm.byline,
                  Ink::Black, Tracking{}, plane);
  yF26 += pxToF26(bylineF.lineHeight() + kBookEndGap);

  // above it goes too, or the slabs sit a line lower on a book that said nothing.

                    baselineInF26(metaF, yF26, pxToF26(metaF.lineHeight())), vm.meta,

    yF26 += pxToF26(metaF.lineHeight());
  } else {
    // Undo the gap the byline added, since nothing follows it.
    yF26 -= pxToF26(kBookEndGap);
  }

  //
  // FILLED IS THE FOCUS, not the button's identity: the boards fill exactly the slab
  // the focus is on, and the variant changes the TYPE as well as the box (Value700
  // against Label500), which is the part that is easy to miss.

                   vm.focusedAction == BookEndScreen::kLeave, plane);

  // --- The note, bottom-anchored above the hint bar ----------------------------
  //
  // `margin-top: auto` on the board, so it hangs off the BOTTOM and not off the
  // slabs -- which is what keeps it still when the meta line is absent. Wrapped once
  // and then both measured and drawn from that one Prose: two calls that each
  // re-wrapped would be two chances to disagree, and the disagreement reads as a
  // paragraph drifted off position.

  const int barH = hintBarHeight(fonts, hints);
  const int noteTop = fb.height() - barH - kBookEndNotePadBottom - f26ToPx(note.heightF26());
  // LEFT, not the Centre default: the board states no text-align on this block.
  drawProse(fb, noteF, note, kMargin, usableW, pxToF26(noteTop), Ink::Black, plane,
            ProseAlign::Left);

  drawHintBar(fb, fonts, hints, plane);
}

- [ ] **Step 2: Add `handleFinish()`**

Place it directly after `handleOpen`. The globals it uses are `gSd` (the
`SdFileSystem`, **not** `gFs`), `gFactory` (a value, so `gFactory.library()`), and
`gReading`, which already holds the open book's path and size:

```cpp
// The user asked for a book to be marked finished -- from BookEnd, or from the
// item-actions overlay. See Action::finish().
//
// WHICH BOOK IS RESOLVED HERE, not carried in the Action, which is exactly the shape
// handleOpen has for the identical two-caller problem: BookEnd means the book that is
// open, the overlay means the Library's selected row.
static void handleFinish() {
  gApp->clearFinishRequest();  // first, so a write that fails does not re-fire

  const bool fromBookEnd = gApp->top().id() == reader::ScreenId::BookEnd;

  std::string path;
  uint32_t bookBytes = 0;
  if (fromBookEnd) {
    // gReading already holds both, written when the book was opened -- and this is
    // reachable only with a book open, since BookEnd is pushed from the Reader.
    if (!gReading.open) {
      logf("[finish] BookEnd with no open book\n");
      return;
    }
    path = gReading.path;
    bookBytes = gReading.bytes;
  } else {
    reader::LibraryScreen* lib = gFactory.library();
    if (lib == nullptr) {
      logf("[finish] no Library to ask\n");
      return;
    }
    const reader::LibraryItem* item = lib->focusedItem();
    if (item == nullptr || item->entry.isDir) {
      logf("[finish] nothing selected, or a folder\n");
      return;
    }
    // BookEntry::name is a leaf name and never a path, so the path is the Library's
    // current directory joined with it -- handleOpen's own three lines, and the
    // reason neither can live in core/: only the Library knows where it descended to.
    path = lib->path();
    if (path.empty() || path.back() != '/') path += '/';
    path += item->entry.name;
    bookBytes = item->entry.size;
  }

  // KEEP SD TRAFFIC OFF THE DISPLAY BUS. The card shares the panel's SPI with no
  // locking anywhere in SDCardManager, so a transfer racing a refresh is the kind of
  // fault that looks random.
  reader::SpiBusGuard guard;

  // A BOOK NEVER OPENED HAS NO SIDECAR, and marking one finished from the Library is
  // a legitimate thing for a reader to assert -- so a minimal record is BUILT rather
  // than the press refused. `bookBytes` is what makes it a record about THIS book.
  reader::ReadingPosition pos;
  if (!reader::loadPosition(gSd, path, pos)) {
    pos = reader::ReadingPosition{};
    pos.bookPath = path;
    pos.bookBytes = bookBytes;
  }
  pos.finished = true;

  const reader::SaveResult r = reader::savePosition(gSd, pos);
  // NOT FATAL, and this is the one hazard in the feature. writeAll calls
  // noteCardGone() on a write that fails after opening, which pollCardPresence turns
  // into an App rooted at SdMissingScreen -- so acting on this would throw a reader
  // out of a book they can still perfectly well read, over a flag.
  logf("[finish] %s -> %s\n", path.c_str(),
       r == reader::SaveResult::Failed ? "FAILED" : (r == reader::SaveResult::Unchanged
                                                         ? "unchanged"
                                                         : "ok"));

  // ONLY IF IT NAMES THIS BOOK. Clearing it unconditionally would take an unrelated
  // book off Home's CONTINUE block -- another book's state destroyed by this one's
  // button.
  reader::LastRead last;
  if (reader::loadLastRead(gSd, last) && last.bookPath == path) {
    reader::forgetLastRead(gSd);
    gReading.open = false;
  }

  // BOTH, AND SEPARATELY. Each is consumed when its own screen is reachable; one
  // shared flag would let Library, Back, Home clear it before Home ever used it.
  gHomeStale = true;
  gLibraryStale = true;

  // BookEnd leaves the book -- popTo(Library), which stops at the root when there is
  // none, so it lands on Home for a book opened through CONTINUE. The overlay
  // dismisses in place, because its board gives the row no chevron.
  gApp->dispatch(fromBookEnd ? reader::Action::popTo(reader::ScreenId::Library)
                             : reader::Action::pop());
}
```
